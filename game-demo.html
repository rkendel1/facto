🎮 Game Mode Architecture Demo

Architecture Overview

This demo showcases the render-only game pattern with separated concerns:

  • types.ts - Type definitions for game state and actions
  • store.ts - Centralized state management with pub-sub pattern
  • engine.ts - Pure game logic (no rendering)
  • game-layout.ts - Reusable layout helpers (4:3 aspect ratio)
  • memory-game.ts - Render-only component (UI only)

Code Structure

src/lib/game/ ├── types.ts # GameState, GameAction, GameCard interfaces ├── store.ts # GameStore class for state management ├── engine.ts # GameEngine base class + utilities ├── game-layout.ts # renderGameSurface, CSS helpers └── index.ts # Main entry point src/embeds/ └── memory-game.ts # Render-only Memory Game component

Key Features

  • ✅ Separation of Concerns - Logic separated from rendering
  • ✅ Reactive Updates - UI automatically updates on state change
  • ✅ Responsive Design - 4:3 aspect ratio with breakpoints
  • ✅ Reusable Components - Game layout helpers for all games
  • ✅ Type Safety - Full TypeScript support
  • ✅ Testable - Engine logic can be tested independently
